# Wird 1.8.3: the mushaf with TalkBack, a faster start, safer tasbih and khums (pre-release)

Builds on 1.8.2 and installs over it and earlier 1.8.x builds (same signing key, version code 21). It is the v1.8.3 row of `docs/IMPROVEMENT_PLAN.md` section 7.5, plus two of the small features of section 7.4 that you chose (tasbih vibration and screen on, copying and sharing an ayah).

## The mushaf
- **TalkBack can use every ayah.** Each ayah on a mushaf page is now a link: a tap, or TalkBack's link navigation, opens its actions (favourite, Tafsir al-Mizan). Each ayah is also listed in TalkBack's actions menu as «الآية N: المفضلة والتفسير». Before, the page text could only be tapped by sight.
- **Smoother page turns in «ملاءمة الصفحة للشاشة».** Finding the size that fits a page measures it about nine times. This now runs in the background, outside drawing, and the result is remembered per page, screen size, text scale and the stars on that page. Swiping back to a page, or starring an ayah on another page, no longer fits pages again. A page that is still being fitted stays blank for that moment instead of jumping between sizes.
- **The ayah opened from search or favourites is scrolled into view.** With fit mode off and a large text size, the highlighted ayah could be below the screen; the page now scrolls to it once when it opens.
- **The ayah dialog shows the whole ayah** (it scrolls when the ayah is long; it used to stop after six lines), with two new buttons: «نسخ» copies the ayah with its number and its surah, «مشاركة» shares the same text through any app.
- The screen stays on while the mushaf or the ayah reader is open.

## Mafatih and Sahifa reader
- **Long sections open and scroll smoothly.** A section of up to 21,800 characters used to be drawn as one block of text. It is now drawn in blocks of lines (about 1,200 characters each, never cut inside a line), and only the blocks on screen are laid out. The text, its line breaks and its panel look the same, and TalkBack reads it block by block.
- The back arrow points the right way in Arabic (it mirrors with the layout direction), here and in the Quran ayah reader.
- The screen stays on while a section is open.

## Qibla
- **Correct in landscape.** The compass used the phone's portrait axes, so with the phone turned sideways the arrow was off by 90°. The heading now follows the screen's rotation (all four).

## A faster cold start
- Only the Today tab is prepared at start. The Quran, Mafatih, Sahifa, search, adhan-voice and worship screens prepare their data the first time they are opened, and the search index is built the first time search is opened, not on every launch.

## Backup import
- **Imported values are no longer overwritten by the screen that was open.** The tasbih, the make-up prayers, khums (year, reminder, the new draft), the eclipse reminder, the Imsak alarm, the reader text sizes and fit mode are read again right after an import. Before, the next tap wrote the old values over the imported ones. The message still asks for a restart, which the other settings (place, favourites, reminders on the Today tab) need.

## Tasbih
- **Clearing asks first.** «إعادة العدّ», or picking another target while counting, now asks «مسح العدّ؟» before the count is lost. Picking the current target again changes nothing (it used to clear the count).
- **A strong double vibration at 34, 67 and 100** (the end of each part of tasbih al-Zahra), and when the free counter reaches its target, so you can count without looking. It follows the vibration switch in the settings. Ordinary taps keep their light tick.
- The screen stays on while the tasbih is open.

## Khums
- **The figures are kept.** What you type in the calculator is saved as a draft and is there on your next visit, also after closing the app. It is part of a backup. «مسح الأرقام» clears it.

## Small fixes
- The Ramadan timetable's «‹ ›» buttons are read by TalkBack as «الشهر السابق» and «الشهر التالي».
- A downloadable adhan voice can no longer use an id that starts with `own_`, which the app keeps for voices you import from your own files; two imports in the same second now get different ids.

## Compatibility
- Settings, favourites and backups carry over unchanged. Backups are the same format; the khums draft uses a key that 1.8.x backups already accept.

## Verification
- Unit tests (new):
  - the `own_` rule for downloadable voices, and unique ids for two imports in the same second (`OwnVoiceIdTest`)
  - the tasbih stage ends, the same-target rule, and when clearing asks first (`TasbihSafetyTest`)
  - the khums draft: round trip, separators inside a figure, broken or foreign text, the field limit (`KhumsDraftTest`)
  - the import announcement and the draft key in the backup allow-list (`DataReloadsTest`)
  - the fit cache key (favourites on other pages ignored, size and text scale included) and the cache's order (`MushafFitCacheTest`)
  - the Mafatih lines and blocks join back to the exact text for the longest section of the book, and no block is cut inside a line (`ReaderLinesTest`)
- Full unit test run, Android lint, the debug build and the instrumented test APK: see `progress.md`.

## Not verified (needs a person with a phone)
1. Install over 1.8.2: settings, the place, favourites and reading positions are still there.
2. TalkBack on a mushaf page: swipe to an ayah link (or open the actions menu) and activate it; the ayah dialog opens for that ayah. Add a favourite and open al-Mizan this way.
3. Fit mode on: swipe quickly through 20 pages and back; turns are smooth and each page shows at one size without jumping. Star an ayah; only that page changes.
4. Fit mode off, largest text size: open an ayah near the end of a long page from search; the page scrolls so the highlighted ayah is visible. Swipe away and back: it does not scroll again.
5. Ayah dialog: a long ayah (al-Baqara 282) shows in full and scrolls. «نسخ» puts the ayah, its number and «(سورة البقرة، الآية ٢٨٢)» on the clipboard; «مشاركة» opens the share sheet with the same text.
6. Qibla with auto-rotate on: turn the phone to landscape both ways; the arrow points to the same place as in portrait.
7. Cold start: the app opens on Today noticeably faster; the first search still finds results (the index builds then).
8. Mafatih: TalkBack moves through a long section block by block, not line by line. Open the longest sections (for example the Ziyarat al-Jami'a al-Kabira and the Ramadan nights' a'mal); they open at once, scroll smoothly, look as before, and zoom works.
9. Import a backup while the tasbih holds a different count, then tap the tasbih without restarting: the count continues from the imported value. The same for a khums draft and the mushaf text size.
10. Tasbih: «إعادة العدّ» with a count asks first; «إبقاء العدّ» keeps it. Changing the target with a count asks first. The strong vibration comes at 34, 67 and 100, and none with the vibration switch off. The screen does not turn off while counting.
11. Khums: type figures, leave the screen and close the app; they are still there. «مسح الأرقام» clears them.
12. The back arrows in the Mafatih and ayah readers point right (towards the start of an Arabic line).
13. TalkBack on the Ramadan timetable reads «الشهر السابق» and «الشهر التالي».
