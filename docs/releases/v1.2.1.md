# Daily Deeds Reminder 1.2.1

Corrective release for v1.2.0: real content, restored daily Duas & Ziyarat, a faster search engine, and a hardened build.

## Fixed
- **Full Holy Quran for real:** all 114 surahs / 6,236 ayat in Uthmani script are now bundled (`app/src/main/resources/quran/uthmani.txt`, Tanzil-derived text served by alquran.cloud `quran-uthmani`, SHA-256 `0f36e155aa79d2f12fb28b6f573d4588545398eb95c37f39532b26db89236adf`). The generated placeholder verses from v1.2.0 are gone, and integrity tests fail the build if any surah is incomplete or any placeholder appears.
- **Daily Duas & Ziyarat restored:** a "today" card on the Home tab and shortcut buttons at the top of the Mafatih tab open the weekday Duas and Ziyarat screens (which now have a back button). They are also searchable.
- **Tafsir honesty:** the Tafsir entries are short educational summaries inspired by al-Mizan's themes, not quotations of the book. They are labelled as such, shown only for ayat that have an entry, and no generic fallback text is generated any more.
- **Abridged Mafatih texts** are now flagged in the reader instead of being presented as complete.

## Improved
- **Search:** the index is built once on a background thread, queries are debounced, cancellable and run off the main thread; matching ignores diacritics, hamza forms and the dagger-alef/alef spelling difference between Uthmani and everyday Arabic. Results are capped per category.
- **Notifications:** dedicated status-bar icon, no longer wipes the task back stack, no `printStackTrace`.
- **Manifest:** removed the conflicting `USE_EXACT_ALARM`; backups disabled for the private prefs file.
- **Preferences:** `java.time` for day keys; per-day deed state older than 90 days is pruned.
- **Build:** R8 minification and resource shrinking for release builds, release signing read from environment variables only, GitHub Actions CI (tests, lint, debug APK, content/secret guards).

## Known limits
- Tafsir Al-Mizan is **not** bundled as a full text; a licensed source is needed to add it.
- Some Mafatih supplications remain abridged (flagged in-app) pending the full printed text.
- The attached APK is the debug-signed build, as in earlier releases; no Play-signed release keystore exists yet.
- Interactive checks on a physical device or emulator were not possible in the build environment.

## Verification
51 unit tests, 0 failures (44 existing + 7 new: Quran completeness/checksum, tafsir fallback, weekday search); `lintDebug` and minified `assembleRelease` succeed.
