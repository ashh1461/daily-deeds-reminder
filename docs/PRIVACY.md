# Privacy policy / سياسة الخصوصية: Wird / ورد

Effective: 2026-10-13

## English
Wird does not collect, sell or share personal data. There are no accounts, no advertising and no analytics or tracking.

- **On your device only:** favorites, reading positions, deed progress, tasbih and make-up counters, khums year, reminder and prayer settings are stored locally. Backups are files you export yourself and keep or share as you choose; the app never uploads them. If you have used «موقعي», a backup file you export contains the saved place described below, so treat the file as personal. Coordinates read from this version on are rounded to about 1 km; a place saved by an earlier version keeps its original precision until you tap «موقعي» again.
- **Location:** only if you tap «موقعي» (my location), the app reads your approximate last-known location once, rounds it to about 1 km, and stores it on the device as the place «موقعي الحالي» (my current location) to compute prayer times. It does not pick a city. These coordinates are not sent anywhere; if you export a backup file, the file contains them.
- **Network:** the app asks for internet access only for optional adhan voice packs. When you open the voice list or tap download, it contacts GitHub (`raw.githubusercontent.com` and GitHub release hosts) over HTTPS. Like any web request, GitHub can see your IP address; the app sends no identifier. Nothing is uploaded.
- **Notifications and alarms:** used for prayer, adhan and reminder alerts you switch on.
- **Children:** the app is general religious content and does not knowingly collect any data from anyone.
- **Changes and contact:** changes are published in this file in the repository. Questions: open an issue at https://github.com/ashh1461/daily-deeds-reminder/issues.

## العربية
لا يجمع تطبيق «ورد» أي بيانات شخصية ولا يبيعها ولا يشاركها، ولا توجد حسابات أو إعلانات أو تحليلات أو تتبّع.

- **على جهازك فقط:** المفضلة وأماكن القراءة وتقدّم الأعمال والمسبحة والقضاء وسنة الخمس وإعدادات التذكير والصلاة تُحفظ محلياً. النسخ الاحتياطية ملفات تصدّرها بنفسك ولا يرفعها التطبيق، وإن استخدمت «موقعي» فإن ملف النسخة الذي تصدّره يحتوي على المكان المحفوظ، فتعامل معه كملف شخصي. الإحداثيات التي تُقرأ بدءاً من هذا الإصدار تُقرَّب إلى نحو 1 كم، أما المكان المحفوظ بإصدار أقدم فيبقى بدقته الأصلية إلى أن تضغط «موقعي» من جديد.
- **الموقع:** فقط عند الضغط على «موقعي» يقرأ التطبيق آخر موقع تقريبي معروف مرة واحدة، ويقرّبه إلى نحو 1 كم، ويحفظه على الجهاز باسم «موقعي الحالي» لحساب أوقات الصلاة، ولا يختار مدينة. لا تُرسل هذه الإحداثيات إلى أي جهة، وإن صدّرت ملف نسخة احتياطية فإنه يحتوي عليها.
- **الشبكة:** يطلب التطبيق الإنترنت فقط لحزم أصوات الأذان الاختيارية، فيتصل بـ GitHub عبر HTTPS عند فتح قائمة الأصوات أو الضغط على تنزيل، وقد يرى GitHub عنوان IP كأي طلب ويب، ولا يرسل التطبيق أي معرّف ولا يرفع شيئاً.
- **الإشعارات والمنبهات:** تُستخدم لتنبيهات الصلاة والأذان والتذكير التي تفعّلها.
- **الأطفال:** المحتوى ديني عام ولا يجمع التطبيق بيانات من أي أحد.
- **التعديلات والتواصل:** تُنشر التعديلات في هذا الملف. للاستفسار افتح مسألة (issue) على صفحة المشروع في GitHub.
