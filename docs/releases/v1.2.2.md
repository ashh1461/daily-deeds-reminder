# Daily Deeds Reminder 1.2.2

Adds the **complete text of Mafatih al-Jinan** (Shaykh Abbas al-Qummi) to the app.

## New
- **«الكتاب كاملاً» category in the Mafatih tab:** all three Abwab (post-prayer litanies and weekday duas, the Islamic months' devotions, and the Ziyarat) from the opening to the author's closing colophon, split into 103 readable sections with printed-page ranges (e.g. «دعاء كميل (ص 91–99)»). The same reader gives font sizing and copy.
- **Searchable:** the whole book is in the global search index (diacritic- and alef-insensitive), under «مفاتيح الجنان».
- The existing hand-curated, fully diacritized items (Kumayl, Tawassul, Sabah, Ashura, etc.) are unchanged.

## Source and licence
- Text: *Mafatih al-Jinan* by Shaykh Abbas al-Qummi (d. 1359 AH / 1941), an author whose work is in the public domain, taken from the OpenITI corpus (`OpenITI/1375AH`, `1359CabbasQummi.MafatihJinan`; OpenITI is MIT-licensed), itself converted from al-Maktaba al-Shamela. See https://github.com/OpenITI/1375AH.
- Conversion: page/edition markers and the `~~` line joins were removed; text is otherwise untouched. Resource: `app/src/main/resources/mafatih/fullbook.txt`, SHA-256 `678d3b945b610220a28d1791b69083b42f7b09177ea7a042b29f1e0353104c6a`.

## Known limits
- **The full-book text has no tashkeel** (the digitized source is undiacritized). Fully diacritized versions exist only for the curated items.
- The text is a digitization and has not been proofread against a printed edition; typos from the source (e.g. «الجمة» for «الجمعة» in one heading) may remain. Please report any you find.
- Tafsir Al-Mizan full text is still not bundled.
- APK is debug-signed; no device/emulator testing was possible in the build environment.
