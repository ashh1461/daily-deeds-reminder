# Daily Deeds Reminder 1.1.1

Adds weekday duas and ziyarat, improves the Arabic RTL interface, and completes the previously abbreviated Friday and Sunday texts.

- Three bottom tabs: الأعمال, الأدعية, and الزيارات. Weekday content includes a seven-day selector, today's highlight, copying, and font-size controls.
- Redesigned home screen, deed cards, filters, and daily progress summary. Material theme colours improve light/dark contrast; status-bar contrast is corrected.
- Completed Friday's dua and Sunday's Fatima ziyarat, including both printed narrations. Corrected a preposition in Sunday's dua. Printed-page sources and edition variants are documented in [the text review](https://github.com/ashh1461/daily-deeds-reminder/blob/master/docs/content/weekday-text-review.md).
- Split the reader and counter into focused Compose files while retaining existing state and callbacks.

## Distribution

This release merges the release branch into `master`. The APK retains `com.dailydeeds.reminder.debug` and the signing identity of v1.1.0 so existing installations can update without clearing saved progress. Version code: 3.

This remains a debug distribution build for GitHub, not a Google Play production build. Android 8.0 or later is required.
