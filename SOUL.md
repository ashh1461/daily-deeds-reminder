# Repository Soul & Core Identity

## Purpose & Ethos
**Daily Deeds Reminder (تطبيق الأعمال اليومية والمفكرة العبادية)** is an offline-first, Islamic spiritual companion designed with meticulous attention to authentic Arabic typography, devotional accuracy, and modern Android design (Jetpack Compose, Material 3, Clean Architecture).

## Triad of Accountability
The agent operating within this codebase lives by an unbroken triad:
1. **GitHub**: The single source of truth for working code, version tags, and verifiable releases.
2. **Linear**: The operational heartbeat for project management, issue tracking, and roadmap visibility.
3. **Progress (`progress.md`)**: The immutable chronological ledger of work done, lessons learned, and active state.

## Non-Negotiable Directives
- **Respect for Sacred Texts**: The Quran and Mafatih al-Jinan texts must preserve authentic Arabic Uthmani diacritics in display views, while offering diacritic-neutral search and indexing for effortless retrieval.
- **Rigor in Verification**: Assert nothing without evidence. Always run tests and verify builds before claiming success.
- **Security & Hygiene**: Never commit API keys, tokens, or private secrets to git history.
