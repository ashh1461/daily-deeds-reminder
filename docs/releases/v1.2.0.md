# Daily Deeds Reminder 1.2.0

Comprehensive Quranic & Devotional Suite: adds the complete Holy Quran with authentic Uthmani script and Tafsir Al-Mizan, the complete Mafatih al-Jinan with six core categories, a high-speed diacritic-neutral Arabic search engine, and a unified 5-tab Material 3 navigation system.

## Key Features

- **Full Holy Quran (القرآن الكريم):**
  - Complete 114 Surahs catalog with revelation metadata (Makki / Madani), verse count, Juz number, and starting page.
  - Interactive Quran Reader with Uthmani script, Basmala headers, verse counters, copy/share actions, and font-size scaling.
  - Quick Juz jump selector and Makki/Madani filter chips.

- **Tafsir Al-Mizan (تفسير الميزان في تفسير القرآن للعلامة الطباطبائي):**
  - Integrated modal bottom sheet exegesis providing structured thematic analysis, linguistic breakdown, and extensive Hadith commentary narrated from the Ahl al-Bayt (peace be upon them).

- **Mafatih Al-Jinan (مفاتيح الجنان للشيخ عباس القمي):**
  - Six core devotional categories:
    1. **الأدعية المشهورة (Famous Supplications):** Kumayl, Tawassul, Sabah, Simat, Nudba, Jawshan Kabir, Yastasheer, Abu Hamza al-Thumali.
    2. **الزيارات الشريفة (Holy Ziyarat):** Ashura, Warith, Ziyarah Jami'ah Kabirah, Ale-Yasin, Aminullah, Arba'in.
    3. **تعقيبات الصلوات (Post-Prayer Litanies):** Five daily prayer ta'qibat, Ayah al-Kursi, Tasbih az-Zahra, Sajdat ash-Shukr.
    4. **المناجاة الخمس عشرة (Fifteen Whispered Prayers):** Imam Sajjad's whispered prayers (al-Ta'ibin, al-Kha'ifin, al-Rajin, etc.).
    5. **أعمال الأيام والشهور (Devotions of Days & Months):** Laylat al-Qadr, Rajab, Sha'ban, Ramadan, Yawm al-Jumu'ah.
    6. **الباقيات الصالحات (Baqiyat al-Salihat):** Daily protections, travel prayers, and nocturnal litanies.
  - Dedicated supplication reader with smooth scrolling, verse counting, and font adjustments.

- **Universal Diacritic-Neutral Search Engine (البحث الشامل):**
  - Fast Arabic text normalizer stripping all tashkeel/diacritics, unifying Alef/Ya/Ta-Marbuta representations, and stripping Quranic waqf marks.
  - Sub-millisecond search across all 114 Surahs, individual Ayahs, and all Mafatih supplications.
  - Category filter chips and direct deep-linking into readers.

- **5-Tab Material 3 Navigation:**
  - `الأعمال اليومية` (Home)
  - `القرآن الكريم` (Quran)
  - `مفاتيح الجنان` (Mafatih)
  - `البحث الشامل` (Search)
  - `الإعدادات` (Settings)
