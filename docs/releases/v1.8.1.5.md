# Wird 1.8.1.5: the Quran page by page, and deleting favourites from the list (pre-release)

Builds on 1.8.1.4 and installs over it and earlier 1.8.x builds (same signing key, version code 18). It answers two requests from the owner: "the full Quran as pages, not swiping up", and "delete or bulk-delete stars without going to their location".

## The Quran as mushaf pages
- **The Quran tab now opens the mushaf page by page**: the 604 pages of the Madani mushaf, turned sideways like a book (swipe to the right for the next page, as in a printed mushaf). The page layout comes from the page numbers already in the bundled Uthmani text, so every page holds exactly the ayahs of the printed page.
- Each page shows:
  - the surah title and basmala where a surah begins
  - the ayahs as continuous justified text, each closed by its number «﴿٢٥٥﴾»
  - the page number at the foot
- The top bar shows the page, the surah or surahs on it, and the juz.
- **Tap an ayah** to add it to or remove it from the favourites, or to open its Tafsir al-Mizan. Favourite ayahs are marked «★».
- **Go to a page or a juz** from the top bar, or with «صفحة أو جزء» on the Quran tab. Arabic-Indic digits are accepted.
- **Resume where you stopped:** «متابعة: صفحة …» on the Quran tab. The «القرآن» resume tile on the Today screen opens the last page when it is still the same surah.
- **Search results and favourite ayahs open on their page** with the ayah highlighted, instead of at the top of the surah.
- **Each page fits the screen**, so a page is read without scrolling. «ملاءمة الصفحة للشاشة» is on by default (the frame icon in the top bar): each page picks the largest text size at which all of it fits. Dense pages therefore use slightly smaller text than light ones.
- The zoom buttons switch to a fixed size of your choice, starting from the size on screen. A page longer than the screen then scrolls down within the page. Tap the frame icon to return to fitted pages.
- **The old view is still there:** choose «آيات متتالية» on the Quran tab to read one surah as a scrolling list. In that view, search results and favourites now scroll to the ayah too.

## Deleting favourites from the list
- **A delete button on every favourite**, so an item can be removed without opening the surah, du'a or ziyarah it points to.
- **Select several to delete together:**
  - press «تحديد», or press and hold any item
  - tick the items, or press «تحديد الكل»
  - then «حذف», with a confirmation
- **Filter by kind** (الآيات، المفاتيح، الصحيفة، أدعية وزيارات الأيام), each with its count. "Select all" then picks only that kind, so for example all starred ayahs can be cleared at once.
- **Every delete can be undone** with «تراجع» in the bar that appears at the top of the list. It is removed from the favourites only; no text is deleted.

## Compatibility
- **Backups** now include the last mushaf page and the chosen Quran view. Older versions ignore those two settings when restoring; everything else restores as before.
- Favourites keep their format, so lists from earlier versions show as before.

## Verification
- New unit tests:
  - the 604-page layout: every one of the 6,236 ayahs is on exactly one page, in order, and no page is empty
  - pages 1-3 and 604 match the Madani mushaf
  - Ayat al-Kursi is on page 42
  - each surah's start page agrees with the surah table
  - the juz start pages
  - out-of-range pages
  - Arabic-Indic and Persian digit parsing and formatting
  - deleting several favourites while keeping the order
  - the backup allow-list for the two new settings
- Full unit test run, Android lint and the debug build: see `progress.md`.

## Not verified (needs a person with a phone)
1. Turning pages: does swiping to the right go to the next page, as in a printed mushaf? Test both with the phone in Arabic and in English.
2. With fitted pages (the default), no page needs scrolling and the text stays readable, on a small and a large phone and at a large system font size. The densest pages, for example 2:282 on page 48, are the ones to check.
3. Tapping an ayah near a line break opens the right ayah.
4. Search for an ayah, and open a favourite ayah: the right page opens with the ayah highlighted.
5. Favourites:
   - long-press to select
   - «تحديد الكل» with a filter
   - bulk delete
   - «تراجع» brings everything back, also after two deletes in a row
   - the back button leaves select mode
   - rotating the phone keeps the selection and the undo bar
6. Dark theme: the ayah numbers and the highlight are readable.
