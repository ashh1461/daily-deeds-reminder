# Wird 1.8.1.1: reliability fixes (pre-release)

A fix-only update to 1.8.1 from the recheck in [PR #21](https://github.com/ashh1461/daily-deeds-reminder/pull/21) (Linear ALI-20). No new content or features; the texts and permissions are unchanged. It installs over 1.8.1 (same signing key, version code 14).

**This is published as a pre-release** because the fixes have not been exercised on a physical phone yet (see "Not verified on a device" below). It is not marked Latest.

## Prayer alarms
- **Imsak is no longer lost** when a Fajr pre-alert falls on the same minute (10 and 10 by default in Ramadan). Both notifications now arrive.
- **Late alerts are honest.** A reminder delivered late no longer says the prayer time is "now", and a pre-alert that arrives after the prayer time says the time has come instead of counting down to it.
- **A silent or vibrating phone still gets a notification.** When the adhan cannot play (silent mode or a playback error) the normal reminder is left behind instead of nothing.
- Changing the **Hijri offset** replans the alarms and refreshes the widget.
- A **snooze** no longer fires after you switch that prayer off.

## App
- Tapping a reminder while the app is open **opens its section**, and a rotation no longer overrides the section you picked.
- The **Mafatih counter** survives a rotation.
- The 24 MB **al-Mizan** book is copied only when you first open it, not at every start after an install or update. A full disk no longer leaves a broken partial copy, and the error message is in plain Arabic.
- **My location** keeps about 1 km precision (two decimals) when saved.
- **Settings → About** now carries the full attribution the data licences require (OpenITI, Shamela, rafed.net, altafsir.com, the authors, the changes made, CC BY-NC-SA 4.0, GeoNames CC BY 4.0, NASA/GSFC).

## Security and hardening
- The boot receiver is no longer exported, so other apps cannot trigger alarm rescheduling.
- App data is excluded from Android 12+ device-to-device transfer as well as cloud backup (`allowBackup` was already off).
- Documentation (privacy, security, distribution, store listing) now matches what the code does.

## Verification
- 197 unit tests pass (181 in 1.8.1); Android lint 0 errors, 17 warnings (the recorded baseline). The release APK is the signed, minified build, checked with `scripts/verify_release.py` (v2/v3 signature, not debuggable, application id, permissions, certificate, and a digest different from 1.8.1).
- CI on PR #21 passed for the fix commits; the version-bump commit that this release is cut from runs its own CI after it is pushed.

## Not verified on a device (no physical phone available)
Please check on a phone, and tell me if any of these misbehave:
- A reminder tapped while the app is open opens the right section.
- Fajr pre-alert plus Imsak in Ramadan (set the pre-alert to the same number of minutes as Imsak): both notifications arrive.
- Adhan on a phone set to silent: a normal notification is shown.
- The Mafatih counter keeps its value after rotating the phone.
- First open of al-Mizan after install: the book opens and the first start of the app is not slowed.
- The attribution text in Settings → About reads correctly right-to-left.

## Known and unchanged
`targetSdk` is still 34 (planned for the next platform release). The voice-pack catalogue is empty by design and its list cannot load while `voices/manifest.json` is absent from `master`. The store text still says "full-length adhan" although no audio is bundled; that wording is the owner's decision.

## Install
