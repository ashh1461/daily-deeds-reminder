# Wird 1.8.1.3: switch the adhan for all prayers at once (pre-release)

A small update to 1.8.1.2 (the release with the two bundled adhan recordings). It installs over 1.8.1.2, 1.8.1.1 and 1.8.1 (same signing key, version code 16).

**This is published as a pre-release.** It is the first release built from `master` after the whole stack of pull requests (#14 to #21 and the adhan work) was merged.

## Switching between adhans
- **One switch for all prayers:** in «إعدادات الأذان وطريقة الحساب», at the top of «تنبيه كل صلاة», the card «صوت الأذان لكل الصلوات» changes the adhan for Fajr, Dhuhr, Maghrib and Isha in one step. Choices: the Karbala adhan, the Mashhad adhan, «نغمة الهاتف» (the phone's sound), or any voice you imported or downloaded. Its «تجربة» button plays the first 20 seconds of the chosen voice.
- **Each prayer can still have its own voice:** the picker inside each prayer's card is unchanged and overrides the common choice. When the prayers use different voices the card says «مختلف حسب الصلاة».
- **The current choice is marked with ✓** in every voice menu. A stored "default" is shown as the Karbala adhan, which is what it plays.

## Rights of the adhan recordings
The project owner confirmed on 2026-10-14 that both recordings are free of licence restrictions. No licence text, source link or reciter's name accompanies the files (they are MP3s converted from online videos), so this confirmation is the only evidence of the rights and has not been independently verified. Settings → About now says the owner confirmed it. Details: `docs/licenses/ADHAN_AUDIO.md`. The owner should keep the confirmation on record before any store publication.

## Verification
- Unit tests pass, including new ones for the all-prayers switch (which prayers change, that mode, pre-alert and manual offset are kept, and that the stored "default" and the explicit Karbala id count as the same choice). Android lint 0 errors. The release APK is the signed, minified build, checked with `scripts/verify_release.py`.
- The bundled voices were played on an Android 14 emulator in 1.8.1.2 (see `docs/releases/v1.8.1.2.md`); this release changes only the voice menus and the credit text.

## Not verified (needs a person with a phone)
- How the two recordings sound (nobody has listened; only their structure was checked), a full 5-minute playback, and the adhan stopping for an incoming call.
- The new «صوت الأذان لكل الصلوات» card on a real device: layout of the long Arabic names, and that choosing a voice there is reflected in each prayer's card.
- Everything listed as unverified in `docs/releases/v1.8.1.2.md` and `docs/releases/v1.8.1.1.md`.
